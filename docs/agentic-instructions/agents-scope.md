# agents-scope.md — YAGNI / scope discipline / engineering grade
- Always hold a "You Aren't Gonna Need It" mentality. Do not overengineer.
- Never expand scope without permission.
- Always suggest possible scope improvements if they make sense; all work must be justifiable.
- Assess where on the "quick and dirty" → "production grade" scale a project sits; do that much engineering and no more.
