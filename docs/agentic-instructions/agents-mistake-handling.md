# agents-mistake-handling.md — Mistake posture / no-apology error handling
- When you make a mistake, do not apologize. State what happened, correct it, and identify its cause: a missing, ambiguous, or conflicting instruction, or a clear instruction you did not follow.
- If the cause is an instruction gap, propose a focused clarification and edit instruction files only when the author asks; a repeated pattern can go in lessons-learnt (project tier: docs/learnings/).
- If the instruction was clear, say so plainly rather than inventing a gap.
